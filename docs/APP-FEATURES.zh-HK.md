# 領路通 PathGuide 產品介紹

更新於 2026 年 11 月 21 日

領路通是為香港視障人士設計的手機輔助 App，也是本畢業專題的產品構想。它將相機、文字、定位與距離資訊轉成粵語或英文提示，協助使用者了解周圍環境、步行到熟悉或已核實的目的地，以及閱讀指示牌和菜單。使用者可配合白杖、導盲犬及原有定向方法使用。

本文描述完整產品目標。現有版本的畫面、功能和驗收結果見[App 現況](FRONTEND-DESIGN.zh-HK.md#current-state)。

## 使用者可以做甚麼

### 了解眼前環境

按「開始協助」聽簡短提示，用「問一下」查詢物件、文字、距離或下一步。App 按任務調用相機、辨識、測距或導航，並提供文字及按鈕操作。使用者可隨時重讀、暫停、繼續或結束。

- **即時辨識**可讀出支援的物件及畫面左、中、右位置，例如行人、車輛、垃圾桶、護柱、交通錐、樓梯、扶手電梯、圍欄及門。普通相機已足以支援名稱、畫面方位與本機路標重認的基本設計。
- **場景模式**以一個開關控制。開啟後概述相機可見的環境，走動出現重要變化時簡短補充。體驗目標是在重要變化後約 3–5 秒開始讀出相關描述。導航提示可打斷場景旁述，普通物件逐項報名在模式期間暫停。按需看圖問答屬後續功能。描述只涵蓋畫面可確認的內容，距離及通行判斷須由相應的感測與導航能力處理。
- **距離與空間**在裝置支援且量測可信時，提供物件表面距離、空間音效和身體或頭部高度的障礙提示。室內鳥瞰畫面呈現地面、物件、障礙和未知範圍。近距離引導只在有效觀測範圍內提示短路徑，遇到遮擋、轉角或量測失效時提示停下、重新對準或掃描。通行提示須有可靠的地面、位置及障礙證據。

### 步行到目的地

- **戶外導航**可搜尋、收藏或重選目的地，預覽步行路線、距離及預計時間。步行時可重讀、暫停、繼續及在偏離時重算，也可選擇保存 GPS 軌跡及路標。路線指示、環境播報及主動查詢共用語音優先次序。到達附近後由使用者確認入口，有已知室內路線才接續導航。
- **陌生室內探索**從現場指示牌、文字和可核對的路標找下一段方向。有足夠線索才提出候選，否則保留位置及方向未知，提供停下掃描、重試、暫停或求助。首次到訪也可明確開始錄製實際走過的路。
- **錄製新路線**在錄路期間自動取樣。到重要位置按類型或方向標記，App 取相、自動命名並回饋，亦可復原。扶手電梯、斜道、接待處和指示牌可從「更多標記」選擇。取相失敗可在原處再試，稍後可查看已保存的失敗紀錄。只有在必要位置用按鈕確認樓層，未知時可保存草稿。路線名稱可後補，已記錄的標記可加選填文字或錄音備註。按掣才開始錄音，備註隨路線在本機保存，重行確認位置後可按需讀出或播放。
- **重行已知路線**利用已錄路線或經核對的場地資料，確認起點、面向、路標和樓層。經樓梯或升降機轉層後，再核對出口和樓層。可在場地改動後修正路線，並管理、回退或刪除已保存的版本。官方場地地圖及路網可提供候選路線，當下位置與通行狀況仍需現場證據。

首輪專題場地為彩明商場、調景嶺站及香港知專設計學院（HKDI），包括三地間選定的步行接駁。調景嶺站只涵蓋出入口及非付費大堂。出行功能的範圍為步行，乘車、月台及叫車服務留在專題範圍以外。[場地及導航規格](https://github.com/actiondarr/pathguide/issues/16)

### 閱讀日常資訊

- **閱讀文字**從首頁拍攝或選取相片，在手機辨識告示、標籤和指示牌上的繁體中文及英文。使用者可逐段閱讀、找字詞、重讀或停止播報，亦可用同一張相片切換至「菜單查價」，以文字或粵語查詢菜名和價格。只讀到部分文字或讀序不明時，標示待核實之處，可逐區讀出或重拍。遇到多個價格或配對不清時，可查看原文或重拍。
- **指示牌與設施資訊**結合同一指示牌上的文字、圖示及箭嘴，說明設施及相關方向。以連續觀察和標示核對扶手電梯方向，從可確認文字或標示辨別門的推拉資訊，並讀出升降機顯示器或按鈕的可確認樓層和狀態。
- **路口資訊**可描述已辨認的行人燈、燈號和斑馬線。過路判斷由使用者按當下路況及原有定向方法作出。

### 設定、帳號與無障礙操作

iPhone 與 Android 按裝置、感測器及服務提供能力。介面提供繁體中文和英文，語音可選粵語或英文並調校語速。以開啟 VoiceOver 的操作為 iPhone 基本情境，按鍵有可讀名稱和狀態，使用者可瀏覽取相按鈕，再自行決定是否啟用。App 與讀屏協調回饋，並支援 TalkBack、大字、標準鍵盤、點字和適用的系統捷徑。日常操作及設定與開發測試分開。相容耳機的頭部手勢及鎖屏語音導航屬選填能力，提供按鈕替代，鎖屏時另行提示相機能力。

訪客可使用本機基本辨識及已錄路線。使用者可管理或刪除帳號、連結登入方式，以及選填緊急聯絡人。緊急聯絡由使用者主動啟動，再交系統撥號。

### 控制資料與改善體驗

基本辨識和已錄室內路線重行在本機處理，路線的必要照片、特徵及樓層資料留在裝置。普通重行以當下觀察比對已保存的路標，毋須累積新影像。雲端分析、問題回報及訓練各自取得同意，雲端分析只送當次所需相片。

「閱讀文字」的相片與辨識結果預設只在本次閱讀暫存。重拍、改選其他相片或離開功能時清除 App 的暫存。相簿原相由使用者管理。

使用者可回報物件認錯、漏認、測距不準或文字配錯，查看進度及撤回相關同意。選擇改善已錄路線時，App 可保留有限候選畫面，由覆核人員在行程後核實。核實結果可補強本機路標記憶。經另外同意的必要資料才可用於私人路標模型批次訓練。

共用模型改善與私人微調均須在獨立資料或另一趟行程比較成效。通過品質與相容性檢查後，使用者才會收到更新，可查看改動、限制和回退選項。[資料與服務契約](BACKEND-DESIGN.zh-HK.md) · [模型與品質驗收](DATASET-REVIEW.zh-HK.md)

## 主要工具及用途

| 工具 | 在產品中的用途 |
|---|---|
| Flutter／Dart，Swift／Kotlin | 共用介面、任務流程和無障礙文案，透過原生程式連接相機、感測器、地圖及語音 |
| AVFoundation／CameraX，YOLO／TensorFlow Lite（LiteRT） | 管理相機取樣和手機端辨識，讓基本物件提示可在本機運作 |
| Apple Vision、平台 OCR、系統語音辨識及 flutter_tts | 提取路標特徵，將圖中文字整理成可查詢的內容，提供語音輸入與粵語／英文播報 |
| Qwen-VL（qwen3-vl-plus）及視覺語言模型 | 雲端分析補充物件清單難以表達的畫面內容，服務端保管憑證並控制請求。另評估本機模型的回應品質、速度及資源需求 |
| ARKit、LiDAR 及原生深度能力 | 在適合的裝置分別評估姿態追蹤和選填測距，為幾何、鳥瞰和空間提示提供依據 |
| MapKit／Core Location，Android 地圖、Places／Location 及 Routes 服務 | 搜尋戶外地點、計算步行路線與更新位置 |
| 室內拓撲圖、路徑搜尋及可選的 CSDI 圖資 | 以有方向的路段連接路標與樓層，供已知場地查找路徑，按可用資料提供地圖輔助 |
| Firebase Auth、Firestore、Storage、Cloud Functions 及 App Check | 管理身分及存取權，支援經同意的雲端分析、照片覆核與模型交付 |
| 本機偏好設定、安全儲存及加密佇列 | 保存語言、語速、路線版本及待傳資料，按用途控制保存及傳送 |
| Python、PyTorch、Ultralytics、Colab／雲端 GPU | 整理資料、訓練、比較候選及匯出手機模型，讓實驗可重現 |
| Git／GitHub、Flutter 測試、XCTest 及實機測試 | 對照程式、模型與文件版本，驗證行為及保留回退依據 |
